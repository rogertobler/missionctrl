  # Small CLI for calc.py

  ## Summary

  Add subcommands for add and divide. Accept two numbers and print the result to stdout.

  ## Implementation

  • Replace the current demonstration in __main__ with a main(argv=None) entry point. Keep the existing add() and
    divide() functions.

  • Support python calc.py add 2 3 and python calc.py divide 6 3, plus -h and --help.

  • For an unknown command, the wrong number of arguments, a nonnumeric value, or division by zero, print a short German
    message to stderr and return exit code 2. Successful calculations return 0.

  ## Verification

  Check both commands, help, and each error case. Confirm that each result appears only on stdout and each error appears
  only on stderr.

  ## Assumptions

  Arguments are decimal numbers parsed as floats; results use Python’s normal float formatting. The existing uncommitted
  change to divide() is preserved.
